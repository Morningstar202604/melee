# melee brand assets

See [`docs/BRAND.md`](../../BRAND.md) for the rules.

- `logo-mark.svg` — transparent mark, used in the app and 3D header.
- `logo-badge.svg` — dark tile, used for favicons, installer and social avatars.
- `logo-wordmark-light.svg` — light-surface lockup.
- `logo-wordmark-dark.svg` — dark-surface lockup.

Do not recolor the gold event core, rotate the mark, or put it inside a second badge when the wordmark is present.
