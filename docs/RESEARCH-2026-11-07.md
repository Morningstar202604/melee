# Round research: standards and installers (2026-11-07)

Companion to [RESEARCH-2026-11-04.md](RESEARCH-2026-11-04.md) (17 projects, still current) and
[BENCHMARK.md](BENCHMARK.md). This round studied **protocol standards and packaging practices**
rather than more arenas — because after the 1.8.x fairness work, the gap was no longer
"who do we compare to" but "which mature solutions does the product still miss".

Rule unchanged: a claim here is either **adopted with code + test evidence**, or
**rejected with a concrete reason**. Facts below were read from primary sources on 2026-11-07.

| 1 | [IETF draft-ietf-httpapi-ratelimit-headers-11](https://datatracker.ietf.org/doc/html/draft-ietf-httpapi-ratelimit-headers) | `RateLimit: "policy";r=<remaining>;t=<window>` + `RateLimit-Policy: "policy";q=<quota>;w=<seconds>`; the draft deliberately reports **delay-seconds, not timestamps**, and fields can appear on any status | Rate-limit headers on **every** guarded endpoint, success **and** 429 (429 additionally keeps `Retry-After`). ## Fresh scan of the arena landscape (2026-11-07)

GitHub search over `llm game arena` / `ai battle arena` / `llm agents play games spectator`
returns only micro-projects this cycle (≤2 stars: LLM-GAME-Arena, syntax-brawlers,
AI-Civilization-Arena, Phalanx-Arena…). None has a broadcast layer — no event log, no
replay, no director, no recap. Conclusion unchanged from the 11-04 round: the named
comparables are still FastChat/LMArena, TextArena, lmring, ChatArena, AgentBench and
Lichess; melee's differentiator remains the broadcast layer, and no new entrant closes
that gap in the opposite direction.

## What this round's verification caught (that research alone would not have)

The 12-game external run found three defects the 954-test gate had passed:

1. **Secure-mode matches could not be replayed at all** — `/state` 500, worker could not
   resume, every default-created match was broken end-to-end. (Seed left the public event
   in 1.8.3; `rehydrate` still required it.)
2. **Contract schema required `seed`** that secure mode intentionally omits — every match
   logged a contract violation on write.
3. **Codenames replay rebuilt the board from the wrong word list** (`lang` never reached
   `match.created.config`) — English matches broke at move 18 on replay.

Plus two user-visible ones: the English recap embedded Chinese team names
(`红队 wins: 翻到刺客…`), and the leaderboard query was a full table scan
(4.84 ms → 0.24 ms after the index). All fixed with regression tests; the
counter-proof method (revert the fix, watch the test go red) was applied to each.
