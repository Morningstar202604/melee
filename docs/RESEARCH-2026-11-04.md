# Reference projects deep-dive (2026-11-04)

Companion to [BENCHMARK](BENCHMARK.md): that file compares positioning and stars; this one records what we **studied in depth and adopted** from each project, and where each adoption lives in the code. A reference earns a row here only if something from it actually changed this repository — or if we can explain, concretely, why its signature idea does not fit melee's positioning.

Agent-protocol research (MCP / A2A / AG-UI) is summarized in [docs/AGENT-HARNESS.md](AGENT-HARNESS.md).

## Deliberately not adopted, with reasons

| Project | Signature idea | Why melee does not take it |
|---|---|---|
| FastChat | Anonymous voting → Elo | melee's value is *named* players and narrated stories; anonymous benchmark voting is a different product. OpenSkill season ratings cover the "who is stronger" question without turning the studio into a leaderboard site. |
| LMArena-style public leaderboard | Global cross-provider ranking | Contradicts the self-hosted, per-community positioning; seasons serve this need inside one deployment. |
| AgentBench multi-domain suites | 50+ task environments | Content lives in TextArena's catalogue via the adapter; curating 12 deterministic games with full broadcast affordances beats shallow coverage of 50. |
| AG-UI full vocabulary | 16 event types for agent chat UIs | Our events are match events (moves, cues, narration) with per-player visibility; forcing them into AG-UI's chat parts would lose `visibility` trimming. Documented mapping instead. |
| LangGraph as orchestration | Agents as graph nodes inside the platform | melee keeps orchestration in the caller (HTTPAgent service); the platform

## How this list was built

- Protocol facts (MCP spec revision 2026-07-28, official SDK; A2A agent-card path; AG-UI event architecture) verified against current docs on 2026-11-04; the MCP server uses the official `mcp` SDK (pinned `<2`), the Agent Card follows the current canonical path.
- Lichess relay model (PGN pull/push), TextArena `ta.make` runtime resolution, FastChat's Elo-to-Bradley-Terry history — each read from primary sources before being written here.
- Every "adopted" row names the file and the test that locks it in; rows without code linkage live in the "deliberately not adopted" table.

## The borrowings that changed behaviour this release (quick index)

- Portable export/import + fingerprint: `portable.py`, routes, CLI, 5 tests.
- Registration-time env probe: broken TextArena installs now remove games from the catalogue instead of failing matches later.
- MCP server: `melee mcp`, official SDK, 7 tools, 4 tests.
- Agent Card: `/.well-known/agent-card.json`, frozen-route coverage.
- Webhooks: HMAC-signed dispatch with retry, 4 tests.

Everything else in the table was already part of melee; the row documents the lineage and the test that guards it, which is how adoption stays auditable.
