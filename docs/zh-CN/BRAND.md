# melee 品牌

melee 不是一张带深色模式的仪表盘。它是一场比赛发生的地方。

品牌从这句话出发：一颗亮的事件核心，两边在它上面相遇，外面是一圈暗下来的赛场。克制是品牌的一部分。它应该像凌晨两点的转播控制室，不像 SaaS 落地页。

## 标记

![melee 标记](../assets/brand/logo-badge.svg)

标记是一个 **M**，由两道上升的笔画组成。它们可以是两名选手、两座塔，或对阵表的两边。两道笔画在**金色核心**相遇——那是双方共享的唯一事件。外面一圈细细的青色轨道，是转播面：把比赛带出去的那一层。

它必须能活过 16 px 的 favicon、Windows 安装包图标、3D 顶栏和 1600 px 宽的 README。不要加特效、不要旋转、不要把金色核心换成某一方的颜色。标记是常量，周围的屏幕会变。

## 字标

字标是小写 `melee`，字距收紧，字重偏重，标记在左。小写让语气保持平视；重量让它在 3D 画面旁不会消失。

亮色面用亮色字标，暗色面用暗色字标。不要换字体，也不要在已经有字标的地方再套一层徽标。

## 颜色

| Token | Hex | 用途 |
|---|---|---|
| Ink | `#070B12` | 赛场背景、头图、安装包 |
| Panel | `#111A27` | 卡片与侧轨 |
| Cyan | `#22D3EE` | 直播信号、标记主笔 |
| Blue | `#2563EB` | 标记渐变的另一端 |
| Gold | `#F1C46A` | 事件核心；教练、真相、强调 |
| Mist | `#E8EAF2` | 暗色面主文字 |
| Muted | `#8F9DB2` | 暗色面次文字 |

产品界面保留自己的亮/暗令牌。营销面是暗的，因为赛场是暗的；应用默认亮色，因为控制台需要在白天读得清。这个对比是有意的：**转播是暗的，工作台是亮的。**

## 语气

像一位好解说，不像一份新闻稿。

- 多用短陈述：“棋盘是视图，日志才是比赛。”
- 写具体的东西：事件日志、回合、切镜、教练指令。
- 少用“颠覆”“无缝”“赋能”“下一代”。
- 产品文案不用感叹号。让画面自己兴奋。
- 中文少一点形容词，多一点现场感。

可用句子：

> 每一手，都值得回看。
>
> AI 对局，应该像比赛一样被转播。
>
> 直播是视图，回放是视图，日志才是比赛。

## 排版

- 留白要够。拿不准时，删一张卡片，而不是再加一张。
- 一张构图只用一个强调色。青色是信号，金色是事实。
- 细线、柔光、等宽元数据，比粗边框更合适。
- 截图放进深色框里，不要浮在白底上。
- 营销图里的正文至少 16 px。

## 留白与最小尺寸

- 四周留白等于金色核心的高度。
- 标记最小：favicon 16 px，界面 24 px，印刷 48 px。
- 字标最小高度 28 px；再小就只用徽标。

## 它在产品里的位置

- 顶栏：24 px 标记 + `MELEE / Broadcast`。
- 3D 顶栏：28 px 标记 + `melee` + 金色 `3D` 药丸。
- 浏览器标签与安装包：深色徽标。
- 观战页：只有标记的链接，带可访问名称。

直播画面里，logo 永远不该是最响的东西。它是角落里的签名，不是标题。
