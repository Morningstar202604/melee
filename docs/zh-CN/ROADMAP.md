# 路线图

[English](../ROADMAP.md) · **简体中文**

每一项都必须有**可核对的验收标准**；测不了的东西不配上这页。完成的项移入 [CHANGELOG](CHANGELOG.md)。

版本遵循[语义化](https://semver.org/)：当前是 **1.x**。minor 增加能力但不破坏事件契约；只有改事件 schema 或让现有客户端无法跟随的 API 变更才升 major。

## 下一步（1.10）

| 项 | 为什么 | 验收标准 |
|---|---|---|
| 分布式追踪 | 现在只有请求级指标；跨 worker/队列的慢请求定位不到 | OpenTelemetry 的 trace_id 贯穿 HTTP → 队列 → runner，在 Jaeger 里能看到一场比赛的完整路径 |
| 移动端回放手势 | 目前只能拖时间轴 | 双指缩放棋盘，左右滑动切换比赛 |
| 赛制扩到 16 种 | 内容量决定留存 | 至少新增 4 种确定性赛制，每种都有解说、切镜、战报，并被契约测试自动覆盖 |
| 安装包签名 | 安装包已经存在，但未签名，SmartScreen 仍会警告 | `melee-setup.exe` 使用 SignPath 或等效证书签名；下载运行不再弹警告 |

## 明确不做

这些是决定，不是待办。要重新加入，必须先给出新的理由。

- 平台侧的模型工具：联网、文件访问、函数调用、子代理、多步工具循环。那属于调用方的 HTTPAgent。
- 匿名投票、全站 Elo、账号型多租户、计费。
- TextArena 的完整环境目录；我们只注册经过验证的子集。
- 多队赛制的赛季积分——现有排名模型默认两边。

| 项 | 验收 | 结果 |
|---|---|---|
| 事件流压缩 | 大于 1KB 的 JSON/HTML 走 gzip；SSE 不压缩 | `GZipMiddleware`；`test_compression.py` 断言事件响应有 gzip、SSE 没有 |

### 1.9.1 — 2026-11-08

| 项 | 验收 | 结果 |
|---|---|---|
| 可读的 413 | 超大请求体返回 JSON 错误，而不是连接重置 | 读走声明长度、最多 2 秒；3MB/8MB 实测约 75ms |
| 原子导入 | 导入失败不留下半份数据 | 先全量校验，再单事务写入；回滚测试 |

| 增量时间轴 | 长直播不随事件数劣化 | 5000 事件下 5.2 倍提速，点位精确 |
| 事件分页 | `limit` 下推到 SQL 并有上限 | 10/566 条，上限 5000 |
| 迁移框架 | `user_version` + 有序步骤 + 拒绝更新版本的库 | 8 条测试；旧库升级实测 |
| 韧性门禁 | 真实使用场景进入门禁 | `check_resilience.py`，15 项，第 13 步 |
